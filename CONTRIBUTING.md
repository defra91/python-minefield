# Contributing to Python Minefield

Thank you for considering contributing to **Python Minefield**!

This project was born as a fun way to learn Python and modern developer tooling, and contributions of any kind (bug reports, documentation fixes, feature requests, or code) are deeply appreciated.

## How Can You Contribute?

### 1. Reporting Bugs

If you find a bug, please open an issue on GitHub with:

- A clear and descriptive title.
- Steps to reproduce the problem.
- Your OS and Python version.

### 2. Suggesting Enhancements

Have an idea for a new feature or improvement? Open an issue with the tag `enhancement` and describe what you'd like to see!

### 3. Submitting Pull Requests

1. **Fork** the repository and create your branch from `main`:
   
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. **Make your changes** and ensure your code follows the existing style and conventions.
3. Write unit tests for your change and ensure a test coverage of at least 60%.
4. Commit your changes

   ```bash
   git commit -m "Add your message here"
   ```

5. Push to your fork and open a Pull Request against main.

## Code of Conduct

We use **Ruff** for linting and formatting. Please ensure `uv run ruff check .` passes without errors before submitting a PR.

This project is an amateur one, but we strive to maintain a welcoming and inclusive environment. Please be respectful and considerate in your interactions.

Always try to write clean, readable, and well-documented code. If you are unsure about something, feel free to ask for guidance.

### AI Usage

I am personally not against the usage of AI tools for code generation, but I do not use them myself, or at least I do not use them in agentic mode. I would like to suggest you to do the same. Try to have fun, learn and get the maximum benefits from a genuine and human experience of coding and developing together. If you use AI tools, please be transparent about it in your PR description.

Remember that your ideas, your experience and your creativity as a human is a unique value and could never be replaced by any AI tool. Trust yourself and your own abilities, and do not let AI tools replace your own creativity and originality. That's my personal suggestion and philosophy, but I do not want to impose it on anyone.
